# Environment – A-Frame

**Objetivo:** Explorar o componente Environment do A-Frame.

**Descrição:** Neste exemplo, foi criado um ambiente 3D utilizando o componente Environment. Foi escolhido o cenário `forest`, que gera automaticamente uma paisagem com terreno, árvores e céu.

**Propriedades utilizadas:**
- `preset: forest` – define o tipo de ambiente, neste caso, uma floresta.
- `dressingAmount: 50` – define a quantidade de elementos decorativos presentes no cenário.

**Tecnologias utilizadas:**
- A-Frame 1.7.0
- Environment Component 1.5.0

**Resultado:** Foi criado um cenário 3D com vegetação, árvores, terreno e céu, demonstrando a utilização do componente Environment.
