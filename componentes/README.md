# Animation – A-Frame

**Objetivo:** Explorar o componente Animation do A-Frame.

**Descrição:** Neste exemplo, foi criado um cubo roxo que realiza uma rotação contínua de 360 graus.

**Propriedades utilizadas:**
- `property: rotation` – define a propriedade a animar.
- `to: 0 360 0` – define a rotação final.
- `dur: 3000` – define a duração da animação.
- `loop: true` – permite repetir continuamente.
- `easing: linear` – mantém uma velocidade constante.

**Resultado:** O cubo roda continuamente sobre o seu eixo vertical.
